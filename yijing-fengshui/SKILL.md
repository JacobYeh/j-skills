# Yijing-Fengshui — 玄学辅助

> 个人玄学参考工具，基于用户出生信息的简单推算。
> 性质：**娱乐 + 自我反思**，不替代专业命理师/风水师。
> 决策权重：低 (跟 j-plan / finance-advisor 比, 优先级最低)。

## 数据存储

- `data/jacob_birth.json` — 出生信息 (公历/农历/时辰/出生地)
- `data/jacob_bazi.md` — 四柱八字完整档案 (天干/地支/藏干/主星/纳音)

> ⚠️ **隐私警告**: 八字数据含个人命理信息, 推送到 private repo 可以, public repo 不行。

## 触发场景

- 问"我今年运势" / "这个项目能成吗" / "今天适合做什么"
- 起名 / 选公司名 / 选项目代号
- 看日历选黄道吉日

## 跟其他 skill 的关系

- **j-plan**: 长期规划时, 偶尔参考流年运势
- **j-work**: 跳槽/换岗时偶尔参考
- **finance-advisor**: 投资决策 **不参考** 八字 (基本分析原则, 投资看基本面+估值, 不看命)

## 限制声明

1. 本工具 **不预测未来**, 仅基于出生时间做静态分析
2. 决策必须基于 **逻辑+数据**, 八字最多做心态调整
3. 重大决策 (投资/婚姻/工作) 请咨询专业人士
4. AI 给的玄学答案 **不保证准确**, 当娱乐看
